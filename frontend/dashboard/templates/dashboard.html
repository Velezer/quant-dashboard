    Registered Pine strategy · historical backtest

    Runs a supported saved `strategy()` source on registered SQLite candles, up to the runtime’s bounded history limit. Choose an optional UTC date range to calculate only candles opened within it; leaving both dates blank uses the latest selected bar count. Supported Pine inputs appear below the status and can be overridden for this run. A wide range may be clipped by the selected history cap. Results report the actual sample dates and source. Backtests run as bounded background jobs with progress and a stop control; changing settings requests the previous run to stop. Strategy fills remain approximate and research-only; this does not create an account or place orders.

    Chronological tail check: Pine indicators warm up over the full selected history, while strategy orders are suppressed during training. The validation tail starts as a fresh simulation with initial capital. Choose the training share above. The report includes win-rate uncertainty and monthly return stability as descriptive sample statistics. This single split is not an untouched holdout if you tune the source or inputs against its results.
