PROVENANCE GUIDE

Where registry entries come from

Stockbit

Synced from the public IDX listed-company directory. A successful directory refresh records the source URL and snapshot date.

Pintu

Refreshed from Pintu Retail, Pro Spot, and Pro Futures listings. Some futures entries also retain their earlier regulator-approved code-list provenance.

Tokocrypto

Synced from Tokocrypto’s public symbols API. The API source link and refresh date are saved with each active listing.

Pluang

Seeded from a saved public spot and futures listing snapshot. It is not a live listing refresh; each row shows the snapshot date.

Manual entries

Some existing records were entered manually in the dashboard. They remain unverified unless a supported app-listing refresh confirms them; no source URL is implied.

This provenance documents how the app registered an instrument. It does not certify venue availability, execution support, or candle-source quality.
